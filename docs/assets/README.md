## Cover prompt

Use case: ads-marketing. A restrained wide GitHub README banner for Character Studio. Warm off-white paper, charcoal typography, muted terracotta accent. Exact title: “Character Studio”; exact Chinese line: “选主角 · 搭衣服 · 换姿势”; footer: “AGENT + IMAGE API”. Editorial reference cards of an adult brunette portrait, a cream blouse and beige skirt outfit, and a neutral grayscale standing mannequin lead to a full-body studio fashion photograph. Generous whitespace and clear typography. No fake application UI, third-party logos, additional slogans or watermarks. A brand illustration, not evidence of an actual application result.

English edit prompt: change only the Chinese subtitle to “Character. Outfit. Pose.”; retain the title, photographs, layout, colors and footer. Both covers use the built-in image tool, with no API fallback.
